# Website Bengkel Mesin & Cat (Proyek UTS)

Proyek ini dibangun menggunakan arsitektur **Client-Server**.
- **Frontend:** HTML, CSS, Vanilla JS
- **Backend:** Python (Flask)
- **Database:** MySQL

## 🚀 Cara Menjalankan Server Backend
1. Buka terminal di dalam folder `backend/`
2. Install pustaka Python yang dibutuhkan: 
   `pip install -r requirements.txt`
3. Jalankan aplikasi server: 
   `python app.py`

## 🎨 Cara Membuka Tampilan Frontend
1. Buka folder `frontend/`
2. Klik ganda pada file `index.html` untuk membukanya secara langsung di Web Browser Anda (Chrome/Firefox/Edge).
